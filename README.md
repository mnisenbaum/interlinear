# interlinear

Criador de edições interlineares de textos hebraicos e aramaicos (Chassidut, Chumash, Sidur, Guemará) como sites estáticos:
o original, uma ou mais traduções, transliteração, comentários, referências e áudio, organizados em camadas
e com perfis de leitura (iniciante, intermediário, avançado).

Primeiro livro (teste de referência): **Kuntres HaTefilah** — https://kuntres.netlify.app

Especificação: [`docs/novo-projeto.md`](docs/novo-projeto.md)
